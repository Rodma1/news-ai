推送 Token

本地任务通过以下接口推送文章：

POST /api/v1/news  Header: Authorization: Bearer <token>

推送示例（curl）

curl -X POST https://你的域名/api/v1/news \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "文章标题",
    "url": "https://example.com/post",
    "source": "我的采集",
    "published_at": "2026-09-01T10:00:00",
    "summary": "原文摘要",
    "content": "文章正文（可选，AI 摘要会参考正文前 1200 字）",
    "tags": ["标签1", "标签2"]
  }'

必填：title、url（重复推送会自动去重）。可选：source、published_at、summary、content（正文）、tags（数组）。也支持数组批量推送。详情页会展示 content 正文。
